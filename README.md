# 一二和布布 · 独立爪子跟随版

基于 FEMmaster/bubuyier 的 Windows WPF 源码。包含 Win32 全局键鼠监听、透明置顶桌宠、原有键盘透视与鼠标、分离的 PNG 身体/前爪/闭眼素材。

- 鼠标移动：布布左爪跟随屏幕鼠标位置在小鼠标垫内映射的目标点；左右点击时下压。
- 键盘：依据 KeyboardLayout 实际键帽中心、透视投影和设备旋转计算爪子目标；左右手分开跟随（同时按键亦可响应）。
- 双角色独立随机眨眼。
- 约 60 FPS 更新，爪子位置采用指数插值。

上传整个文件夹内容到 GitHub 仓库根目录，运行 `.github/workflows/build-windows.yml`。Windows 环境构建尚未验证。图层素材由先前角色贴图拆分；遮挡和手臂连接处可能仍需视觉微调。键鼠位移是缩放映射，并非真实屏幕坐标等比例。
