# 一二和布布 V3.0：透明局部变形动画桌宠

这是一个可供 GitHub Actions 构建的 **Windows 10/11 WPF 源码项目**，非已编译 EXE。

- 布布：待机 / 鼠标移动两帧 / 左键 / 右键 / 滚轮，共 6 张透明素材。
- 一二：待机 / 左区敲击 / 中区敲击 / 右区敲击 / 空格 / 连打，共 6 张透明素材。
- 动画帧通过源插画局部网格变形生成，而非将整张角色图片上下抖动；帧切换由全局输入事件控制。
- 无矩形背景，透明无边框悬浮窗；Ctrl + 左键拖动；右键或者系统托盘调整设置。
- 全局键鼠钩子仅使用内存状态，不保存输入内容，也不联网。

## GitHub 编译

将 ZIP 内的**内容**（不要把顶层文件夹一起上传）放进仓库根目录。需要保留 `.github/workflows/build-windows.yml`。通过 Actions 的 `Build Windows EXE` 编译，在 Artifacts 下载。

## 现实限制

这是自动从透明绘图生成的局部变形帧，不是原作者绘制的 12 张独立原画。爪子有真实局部形变与按键响应，但还不是骨骼绑定的高精度逐键敲击。暂未在 Windows 上编译或实际测试。
